# 测测核心产品分析

> 核验日期：2026-07-23<br>
> 研究范围：测测官网、官方应用商店页面、官方公司/合作页面，以及用户提供的当前首页截图。<br>
> 证据纪律：公开页面能直接证明的内容标为“事实”；用户任务链、增长与商业机制标为“推断”。

## 结论

测测的核心不是“首页有很多星座、八字、人格测试入口”，而是一个围绕个人档案持续复用的泛心理与情感服务闭环：

`建立个人档案 → 免费测试/关系工具 → 生成可分享结果 → AI 或达人继续解读 → 社区与关系互动 → 每日情绪内容召回 → 会员/测测币/咨询付费`

首页的彩色宫格只是流量分发层。真正值得借鉴的是：

1. 一份个人资产在测试、关系、报告、AI 和日常内容中反复使用。
2. 测评结果不是终点，后面总有分享、双人分析、AI 解读、讨论或咨询。
3. 低频深任务和高频轻任务同时存在：报告负责价值，每日心情、AI 对话和社区负责留存。

## 二、用户提供首页截图揭示的当前信息架构

截图中的首页可分成四层：

1. 顶部个人档案层：头像、生日入口，以及“更加了解 TA”的关系档案入口。
2. 当日状态层：今日心情总分，以及爱情、财富、事业、学习、人际等分项内容。
3. 工具分发层：人格、星座、星盘、生辰、缘分合盘、倾诉、智慧卡、报告等入口。
4. 持续消费层：内容卡片、消息、中心 AI 问答、在线服务和“我的”。

这说明首页并非一条线性业务流程，而是一个“个人档案驱动的多工具消费中心”。中心问答入口和在线服务常驻底部，使任何内容消费都能继续转为对话或人工服务。

## 三、产品飞轮：事实与推断

### 1. 获客

事实：人格测试、心理测试、星盘、八字等功能门槛低，部分报告可免费查看；结果支持好友双人分析和朋友圈人格分布。

推断：免费测试与可分享结果承担低成本拉新，双人分析把一个用户自然扩展成两个人或一个朋友圈。

### 2. 激活

事实：用户可获得人格、个人报告、关系分析等结果，并可继续进入 AI 解读、达人咨询或讨论区。

推断：真正的激活时刻不是“完成答题”，而是“看到一条觉得与自己有关、并愿意继续追问或分享的解释”。

### 3. 留存

事实：产品提供今日心情、每日锦囊、心情曲线、AI 对话、社区话题、消息与关系互动。

推断：测测同时使用五种回访理由：

- 日常回访：今日心情、每日锦囊、心情曲线；
- 内容回访：社区信息流、话题和互动消息；
- 关系回访：双人分析、好友人格分布；
- 情绪回访：AI 陪伴、树洞、真人达人；
- 资产回访：个人档案、历史测试和报告。

### 4. 付费

事实：App Store 披露连续包月、包季、包年和 SVIP；同时存在多档测测币充值。包季会员说明中明确包含心情曲线、AI 解读工具和其他优惠。

推断：商业化不是单一报告付费，而是“订阅权益 + 虚拟币 + 真人服务交易”。免费工具负责流量，AI/报告负责价值感，真人服务承担高客单转化。

## 四、对“关系清晰卡”的映射

### 应当借鉴

| 测测机制 | 关系清晰卡的正确映射 | 优先级 |
| --- | --- | --- |
| 一份档案多场景复用 | 建立“我的沟通画像”和“关系档案”，复用自测结果、六字段摘要、镜像和报告结论 | P0 |
| 测评后连续承接 | 把“评测完成 → 分享预览 → 继续校准”做成同一结果页上的真实可点击主链 | P0 |
| 单人结果扩展到关系 | 做“沟通偏好对照”或“双方关注点对照”，避免输出伪科学默契分 | P1 |
| 高频轻任务 | 增加“今日心情 + 一条清晰练习”，不制造爱情/财富等预测分数 | P1 |
| AI 常驻入口 | 将“问”作为随处可进入的事实整理/情绪承接入口，并保持安全路由 | P1 |
| 结果资产化 | 首页展示最近一次评测、进行中的关系任务、已生成报告和可继续动作 | P1 |
| 分享传播 | 分享脱敏后的沟通画像或清晰卡预览，并允许分享前预览和取消 | P1 |

### 不应照搬

1. 不照搬星座、八字、运势和“爱情/财富分数”。关系清晰卡的承诺是整理事实与感受，不是预测。
2. 不照搬首页的高密度功能宫格。现阶段业务闭环尚未全部验证，继续加入口会放大假功能。
3. 不立即建设开放社区。UGC、私信、未成年人、内容审核和危机干预会显著扩大合规与运营边界。
4. 不立即复制真人咨询市场。它需要资质审核、供给运营、服务质控、支付和售后体系。
5. 不在核心流程可用前接会员或虚拟币。当前最重要的价值验证仍是用户能否完成评测、查看结果、继续校准和生成报告。

## 五、建议的产品主链

关系清晰卡下一版可收敛为：

`18+ 与 AI 边界确认`

`→ 首页选择“我想认识自己 / 我想理清一段关系 / 我只想先说一说”`

`→ 完成对应轻任务`

`→ 获得可保存的沟通画像或关系清晰卡`

`→ 分享预览 / 继续校准 / 开始一次行动`

`→ 回到首页看到最近进度和今日清晰练习`

首页只需要一个强主入口、三个场景入口、一个最近进度区和一个常驻安全/AI入口。视觉可以参考测测的清爽色调和卡片密度，但信息架构要围绕这条主链，而不是复制其栏目数量。

## 六、当前最先修的功能

1. 人格测试必须展示完整题干和选项，并逐题前进。
2. 评测完成页必须真实渲染结果，而不是仅改变隐藏状态。
3. “分享预览”必须进入脱敏预览页，可取消，不得直接分享。
4. “继续校准”必须带着当前评测结果进入关系六字段，而不是创建空任务或无响应。
5. 首页必须显示最近一次结果/进行中任务，让结果成为可复用资产。
6. 以上真实 GUI 路径通过后，再增加今日心情、日常练习或 AI 常驻入口。

## 七、限制与推翻条件

- 官网页脚仍显示 9.60.4，而 App Store 当前显示 10.48.0；官网适合确认产品定位，不足以还原最新版全部界面。
- 官网披露的用户数、咨询师数属于企业自述，本报告未找到独立审计数据。
- 本轮没有登录测测 App 逐屏操作，因此具体推荐排序、付费墙位置和各入口转化率未知。
- “个人档案驱动的飞轮”属于基于官方功能结构和首页截图的产品推断，不是测测披露的经营数据。

如果实际登录流程显示测试、关系分析、AI、社区和付费之间没有复用档案或连续承接，则应推翻“档案驱动闭环”的判断，并改为多工具聚合平台模型。
