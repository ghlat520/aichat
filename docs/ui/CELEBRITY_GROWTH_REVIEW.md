# 自我探索、温暖陪伴与分享交互评审 V1.2

日期：2026-10-26。范围：本地 UI 原型。沿用 A 版，新增 5 个页面，总计 28 页。源码与资源继续维护在 `docs/ui/`。

## 本次解决的问题

原有自测主要由用户主动发现；分享停留在文本预览；个人经历一次展示两段长表单。本次增加一个可讨论的话题入口，让用户有好奇、表达自己和邀请朋友交流的理由，再直接进入免费体验。

预期变化：用户可以完整体验“猜名人 → 看公开线索 → 测自己 → 保存海报 → 朋友定向进入”的路径；答题每题点一次即可前进；经历每次只填写一段的三项短内容。传播率、留存和获客成本仍需真实使用数据验证。

## 页面与交互

| 页面或入口 | 用户得到什么 | 可体验的行为 |
| --- | --- | --- |
| 自测首页的名人观察卡 | 一个熟悉、容易参与的话题 | 打开马斯克偏好猜想 |
| `celebrity` | 先选自己的猜想 | INFP、INTJ、ENTP 或暂不能确定 |
| `celebrity-insight` | 看公开事实与不同解释 | 查看来源、开始自己的自测、生成挑战海报 |
| 答题页 | 一屏一题、完整文字选项 | 自动保存并下一题，也可关闭自动前进；上一题、暂停、失败重试保留 |
| 个人经历 | 每次只写一段 | 情境、行动、结果各一句话；能量感受选填；两段仍需本人确认 |
| `share` | 自己愿意分享的一张卡 | 名人猜想、个人偏好、优势三种海报；保存真实 PNG |
| `invite` | 延续朋友分享的话题 | 直接进入所选测评，或先参与名人话题 |

基础结果完整免费。分享是自愿操作，不作为看结果、获得正常报告内容或继续作答的前置条件。页面不使用虚构投票数、相似度或排名。

## 名人素材与分析表达

首个选题只使用马斯克，避免把未经核对的名人资料批量铺开。

依据：[Tesla，Elon Musk 署名文章，2006-08-02](https://www.tesla.com/secret-master-plan)。文章描述长期能源目标及分阶段车型规划；本原型据此讨论工作表达方式。该材料没有给出他的 MBTI 测评结果，类型选项为讨论假设。

公开事实、编辑解读和无法判断的部分分别展示。用户的猜想不进入本人的测评计分。正式使用大模型辅助研究时，也应保留来源及日期，再审核解读；本轮仍是编辑整理的演示内容。

## 经典题与输入体验

性格特质交互选取 [IPIP-50 官方条目及施测说明](https://www.ipip.ori.org/New_IPIP-50-item-scale.htm)中的第 1、2、3、4、15、6 题，做中文适配展示。原始条目、5 级描述选项和来源可从页面查看。IPIP 的条目及量表为公有领域资料，参见 [IPIP 官方主页](https://www.ipip.ori.org/)。

这 6 题只用于交互评审，不能当作正式 50 题结果。正式版应固定完整工具、中文表述和计分版本。MBTI 与优势测评仍接入最终选定的成熟工具题库，不由大模型临时编题或改分。

选项改为整行大按钮，默认点选后自动保存、进入下一题。可关闭自动前进；“说不清／居中”保留为中间选择。保存失败保留选择并提供重试。

经历采用两步填写。话题提示只帮助回忆，不自动填成用户自己的真实经历；能量词由用户主动选择，确认页仍允许编辑。

## 海报、转发与直达

海报 PNG 为 900 × 1380，含标题、个人表达、产品名称、参与理由和小程序码预留位置。个人经历默认不进入海报；用户主动勾选后才加入摘要。

原型可以下载真实 PNG、预览微信好友卡片并模拟接收方打开。小程序码位明确标示为示意，不是已签发的可扫码正式码。

正式接入采用微信分享路径参数和带场景值的小程序码。依据：[腾讯云 CloudBase 官方带参分享与小程序码说明](https://docs.cloudbase.net/recipes/add-share-with-params-miniprogram)。好友分享与朋友圈分别按相应微信接口处理；生成码时使用有效发布页面，接收方解析参数后定向进入功能。

本轮演示链接示例：

```text
self-growth-prototype.html?screen=invite&entry=traits&campaign=musk-v1&kind=challenge
```

- `entry`：`mbti`、`traits`、`strengths` 或 `voices`，对应用户选择的功能。
- `campaign`：名人话题或个人分享来源。
- `kind`：挑战、偏好或优势海报。
- 正式码的 `scene` 用短标识关联上述配置，例如 `mk01_tr_v1`；不塞入完整报告或经历。
- 自测的正式原生落地拟复用并升级 `pages/assessment/assessment`；人物故事将有对应原生页。当前新增页面仍在浏览器原型中，真实分享和签码接口尚未接入。

接收方使用新的访客状态开始，不继承分享者的私有经历或报告；可以直接开始测评，不用先登录、填长表单或再次分享。

## 验收与后续重判

本地验收要求：四个猜想都能进入线索页；经典题来源可查；点选、改答案、暂停和失败重试可用；两段短经历可确认进入画像；PNG 可下载且文字与当前选项一致；模拟接收方能直接进入选定测评；28 页在手机和桌面尺寸下无横向溢出。

正式上线后分开观察：话题曝光 → 猜想参与 → 自测开始 → 完成 → 自愿分享 → 接收方到达 → 接收方完成。若话题有人看却少人开始，调整桥接文案；若分享多而接收方不完成，检查定向入口与答题成本；不能用海报下载量代替新增用户或付费验证。

## V1.2：遇见，更好的你自己

自测页的主文案改为“遇见，更好的你自己”。整体从用户当下的需要出发：想更懂自己、最近有点难、有个选择想想。保持清楚的免费边界与工具来源，让专业内容以更容易亲近的方式出现。

新增 `voices`（借一点力量）与 `voice`（他们走过的路）。每段内容包含一句可核对的原话、人物当时遇到的处境、他如何往前走，以及编辑整理的一个小提示。原话、经历概述和应用提示分开表达；不把名人经验写成每个人都必须照做的标准。

本轮核对的一手来源：

- [斯坦福大学：乔布斯 2005 年毕业演讲全文](https://news.stanford.edu/stories/2005/06/youve-got-find-love-jobs-says)。选取“重新做初学者的轻盈”片段，讨论重新开始。
- [达特茅斯学院：费德勒 2024 年毕业演讲全文](https://home.dartmouth.edu/news/2024/06/2024-commencement-address-roger-federer)。选取“一分”片段，讨论如何从一次失误回到下一次行动。
- [亚马逊：贝索斯 2016 年度致股东信](https://www.aboutamazon.com/news/company-news/2016-letter-to-shareholders)。保留企业决策语境，借用可调整选择、小步验证的思路。

中文引语标注翻译或节译，原文可从页面打开。用户可以留一句选填笔记、收藏这段力量，或生成“一句力量”海报。笔记默认不进入海报。力量海报的接收方直接看到相应故事，也能继续认识自己。

本轮仍为本地编辑内容与交互原型，没有把这些故事呈现为实时大模型输出。正式服务可用经过核对的素材库辅助生成个性化解释；原话与来源不由模型编造。

力量海报直达示例：`self-growth-prototype.html?screen=invite&entry=voices&kind=comfort&campaign=voices-v1&voice=federer`。`voice` 指向已核对的人物片段；接收方一键打开该片段。
