# 关系清晰卡 UI 原型

项目的原型 UI、评审入口及展示素材统一放在本目录。后续继续在这里迭代，正式小程序代码仍在 `miniprogram/`。

在项目根目录启动：

```bash
cd /Applications/soft/CodeSpace/aichat
npm run ui
```

浏览器打开 **http://127.0.0.1:4188/**。若该端口已在运行，直接打开即可。独立启动也可以使用：

```bash
python3 -m http.server 4188 --bind 127.0.0.1 --directory docs/ui
```

页面为静态 HTML，无需安装前端框架、构建或启动后端。编辑 HTML/CSS/JavaScript 后，刷新即可查看。停止服务使用 `Ctrl+C`。

| 文件 | 内容 |
| --- | --- |
| `index.html` | 原型评审总入口及关键页面直达 |
| `self-growth-prototype.html` | 自测与个人成长 V1.2，共 28 个可点击页面，沿用已选 A 版视觉 |
| `self-growth-social.js` | 名人观察、经典题交互、陪伴故事及 PNG 海报脚本 |
| `cece-preview.html` | 原有产品原型，保留 A/B/C 三种首页方案与原有页面 |
| `native-ui-gallery.html` | 2026-10-25 的 14 页原生小程序截图对照；历史验收依据 |
| `assets/native/` | 原生对照页使用的截图 |
| `assets/previews/` | 总入口与评审使用的预览图 |

`docs/prototypes` 保留为指向 `docs/ui` 的兼容链接，原有路径和当前本地链接仍可使用；所有实际原型页面只维护本目录这一份。

## 本次评审路径

依据：[自测与个人成长功能说明书 V1.0 评审稿](../AICHAT_SELF_ASSESSMENT_PRODUCT_SPEC_2026-10-26.md)。

0. 名人观察 → 公开资料线索 → 我的自测 → 可保存 PNG 海报 → 模拟朋友点开、定向开始。
1. 自测首页 → 三项测评介绍 → 答题、暂停与续答 → 完整免费结果。
2. 补充两段经历 → 确认经历 → 综合画像 → 个人优势说明书预览。
3. 购买确认 → 模拟支付待确认 → 查询订单 → 已购报告。
4. 集中校准 → 修订版 → 一个小行动 → 7 天内一次复盘。
5. 我的报告 → 分享预览 → 订单与售后。
6. 第二期：职业补充输入 → 方向比较 → 补差升级 → 职业报告。

桌面左侧是全部页面目录，右侧有当前页审核点、状态切换和快速体验预设。底部页面选择器在手机尺寸下也可使用。主导航为：首页、自测、说一说、清晰卡、我的。

示例直达：

```text
http://127.0.0.1:4188/self-growth-prototype.html?variant=A&screen=discover
http://127.0.0.1:4188/self-growth-prototype.html?variant=A&screen=preview
http://127.0.0.1:4188/self-growth-prototype.html?variant=A&screen=career
```

原型输入只存于当前页面内存，刷新会重置。每项测评使用 6 道交互演示题，正式题数、耗时、供应商版本及结果字段待实际工具确认。价格沿用说明书的评审提案，支付只做本地模拟。

## 迭代约定

- 先更新本次原型并评审页面，确认后再开发对应小程序功能。
- 复用 A 版色板、插画及五个底部导航，新增页面从现有入口衔接。
- 同一个交互仅保留一个原型源文件，使用 `screen` 参数直达页面，避免页面副本漂移。
- 一期与二期在评审界面分别标出。模拟状态与原生验收截图分别标明用途，不混称真实业务交付。

名人观察、经典题目、海报与直达流程的本轮评审说明见 [传播与轻交互评审](CELEBRITY_GROWTH_REVIEW.md)。正式小程序码与微信转发尚待真实小程序页面接入；原型中可以保存 PNG 并模拟接收方路径。

V1.2 的 28 屏已于 2026-10-26 在 `miniprogram/` 完成原生实现并通过一对一复核（32/32 冒烟 + 34/34 单测），逐屏对照与差异清单见 [原生实现复核](../NATIVE_GROWTH_IMPLEMENTATION_REVIEW_2026-10-26.md)。
