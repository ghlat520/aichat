# 关系清晰卡 UI 原型

项目的原型 UI、评审入口及展示素材统一放在本目录。后续继续在这里迭代，正式小程序代码仍在 `miniprogram/`。

在项目根目录启动：

```bash
cd /Applications/soft/CodeSpace/aichat
npm run ui
```

浏览器打开 **http://127.0.0.1:4188/**。若该端口已在运行，直接打开即可。独立启动也可以使用：

```bash
python3 -m http.server 4188 --bind 127.0.0.1 --directory docs/ui
```

页面为静态 HTML，无需安装前端框架、构建或启动后端。编辑 HTML/CSS/JavaScript 后，刷新即可查看。停止服务使用 `Ctrl+C`。

| 文件 | 内容 |
| --- | --- |
| `index.html` | 原型评审总入口及关键页面直达 |
| `self-growth-prototype.html` | 自测、个人成长与觉察日记，共 33 个可点击页面，沿用已选 A 版视觉 |
| `self-growth-social.js` | 名人观察、经典题交互、陪伴故事及 PNG 海报脚本 |
| `self-growth-diary.js` | 觉察日记的五个评审页面与内存交互，样式仅作用于日记区域 |
| `self-growth-mbti.js` | 最新觉察日记版本内的 MBTI 界面：四维介绍、40 道中文示例题、单题自动切换与 ENTP 十二章节结果样例 |
| `cece-preview.html` | 原有产品原型，保留 A/B/C 三种首页方案与原有页面 |
| `native-ui-gallery.html` | 2026-10-25 的 14 页原生小程序截图对照；历史验收依据 |
| `assets/native/` | 原生对照页使用的截图 |
| `assets/previews/` | 总入口与评审使用的预览图 |

`docs/prototypes` 保留为指向 `docs/ui` 的兼容链接，原有路径和当前本地链接仍可使用；所有实际原型页面只维护本目录这一份。

## 本次评审路径

依据：[自测与个人成长功能说明书 V1.0 评审稿](../AICHAT_SELF_ASSESSMENT_PRODUCT_SPEC_2026-10-26.md)。

0. 名人观察 → 公开资料线索 → 我的自测 → 可保存 PNG 海报 → 模拟朋友点开、定向开始。
1. 自测首页 → 三项测评介绍 → 答题、暂停与续答 → 完整免费结果。
2. 补充两段经历 → 确认经历 → 综合画像 → 个人优势说明书预览。
3. 购买确认 → 模拟支付待确认 → 查询订单 → 已购报告。
4. 集中校准 → 修订版 → 一个小行动 → 7 天内一次复盘。
5. 我的报告 → 分享预览 → 订单与售后。
6. 第二期：职业补充输入 → 方向比较 → 补差升级 → 职业报告。
7. 觉察日记 → 六维觉察树 → 写下此刻 → 保存、回看和编辑 → 回信示例与对应虚构日记。

桌面左侧按“一级功能 → 二级页面”展示目录，打开某个一级功能后显示所属页面；右侧标明当前功能归属、审核点、状态切换和快速体验预设。手机底部的页面选择器使用相同分组，前后切换也按此层级顺序进行。主导航为：首页、自测、觉察日记、说一说、我的；关系清晰卡保留在“我的”中。总入口同样按这五个一级功能组织，展开后直达二级页面。

| 一级功能 | 二级页面范围 | 页面数 |
| --- | --- | --- |
| 首页 | 首页总览 | 1 |
| 自测 | 测评介绍、答题与续答、结果、经历、画像、预览、职业输入、陪伴故事、名人观察等 | 15 |
| 觉察日记 | 六维觉察树、写下今日觉察、日记回看、日记详情、一封回信 | 5 |
| 说一说 | 现有倾诉对话页 | 1 |
| 我的 | 我的空间、报告、校准、复盘、购买、支付、订单、分享与关系清晰卡 | 11 |

本次审核直达：`http://127.0.0.1:4188/self-growth-prototype.html?variant=A&screen=diary&review=diary-20261102-v2`。五个新增页面的 `screen` 分别为 `diary`、`diary-write`、`diary-journal`、`diary-entry`、`diary-letter`。总入口附觉察树、填写页与回信的手机尺寸原型图。URL 的 `review` 参数用于避开浏览器保存的旧版 HTML 缓存。

本次 MBTI 调整直接扩展上述含觉察日记的 33 页原型，自测第一个入口明确为“MBTI 性格测试”。介绍完整采用用户指定的用途说明。四个维度依次对应 E/I、S/N、T/F、J/P，各 10 题、五档选择。每次展示一题，圆圈选中后先着色打勾，约 320ms 后自动进入下一题；上一题、暂停和续答保留选择，未答完 40 题不能通过末题绕过。介绍页也可直接查看 ENTP 排版样例。

结果按用户给定文案排成 ENTP / 发明家型人格，以及特点概况、特点详解、人际关系、基本描述、优势、劣势、适合岗位、适合领域、爱情、感情中的优点、感情中的弱点、ENTP型爱人共 12 节；目录可定位章节，优势与弱点使用条目列表。结果明确标注为固定 ENTP 排版样例，没有根据选择实际计分。

中文题目是用于审核交互的原创示例；五档双向选择的界面参考 [OEJTS](https://openpsychometrics.org/tests/OEJTS/)，不作为 OEJTS 官方译本或正式量表。本目录原型先行评审后，本次 MBTI 改动已于 2026-11-03 按 1:1 接入原生小程序（`growth-content.js` 40 题题库与 12 章节结果、`growth-intro` / `growth-question` / `growth-result` 三页、`assessment` 与 `invite` 入口文案）；原生完成来源标注沿用"40 题中文 UI 示例 · 未进行正式计分"，结果页固定展示 ENTP 样例（2026-11-03 原型 v2 已同步原生：人格摘要卡 + 八维雷达图 + 简短性格分析 + 目录与 12 章节卡，雷达以静态 SVG 数据 URI 复刻原型几何），后端未涉及。
