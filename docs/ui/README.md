# 关系清晰卡 UI 原型

原型 UI、评审入口与预览素材统一在 `docs/ui/` 维护。当前版本以 MBTI、VIA 性格优势、两张参考表和觉察日记为核心；正式小程序实现与原型审核分开验收。

## 启动与总入口

在 aichat 项目根目录运行 `npm run ui`，打开 `http://127.0.0.1:4188/`。端口已运行时直接使用；静态页面无需安装框架或连接后端。

最新审核入口：`http://127.0.0.1:4188/self-growth-prototype.html?screen=discover&review=assessment-20261103-v10f`。版本参数用来避开旧 HTML 缓存。

## 当前功能结构

桌面目录、手机页面选择器、前后切页与总入口采用同一组当前页面，共 **27 页**。

| 一级功能 | 页数 | 当前范围 |
| --- | ---: | --- |
| 首页 | 1 | 首页总览 |
| 自测 | 9 | 先读 16 型优缺点，或分别进入 MBTI、VIA 的介绍/答题/免费结果，另有 VIA × MBTI 对照 |
| 觉察日记 | 5 | 觉察树、写日记、回看、详情、回信示例 |
| 说一说 | 1 | 倾诉对话原型 |
| 我的 | 11 | 当前免费结果、原有报告、复盘、订单、分享与关系清晰卡等 |

五个底部菜单仍为：首页、自测、觉察日记、说一说、我的。关系清晰卡在“我的”中。

## 自测的九个页面

| 页面 | `screen` | 主要交互 |
| --- | --- | --- |
| 自测首页 | `discover` | 轻阅读入口在主标题下、正式测评卡片前；三个卡片为 MBTI、VIA、VIA × MBTI 对照 |
| MBTI 16 型优缺点 | `mbti-types` | 看自己/看 TA、类型与分组筛选，进入 MBTI 自评或带类型进入 VIA 对照 |
| MBTI 测评介绍 | `intro` | 用途、40 题作答方式、继续作答、独立结果排版样例 |
| MBTI 答题与续答 | `question` | 四维各 10 题，一题一卡；五圈选中即保存，320ms 后自动切题 |
| MBTI 免费基础结果 | `result` | 人格摘要、八项倾向多边形、简析、对应类型的名人共鸣卡、目录和 12 张章节卡片 |
| VIA 性格优势介绍 | `via-intro` | 六类美德、24 项优势、72 题说明，实际自评或独立样例 |
| VIA 答题与续答 | `via-question` | 每项 3 题；单题自动切换、换维度、返回修改、暂停续答 |
| VIA 免费基础结果 | `via-result` | 三题均分排序，前 5 与完整 24 项，回看作答与参考阅读 |
| VIA × MBTI 对照表 | `via-mbti` | 16 型各 5 项优势参考、各 4 位名人与共鸣引导，可筛选并带同一类型返回优缺点资料 |

原来的性格特质、优势探索入口与预置免费记录不再出现在当前自测流程。导入、经历、综合画像、职业、名人传播等 11 个旧扩展页退出当前目录；旧 URL 保留兼容访问，并标为“历史扩展”，不混入当前 27 页。

当前自测页的快捷预设只保留“回到自测首页”和“从首次使用开始”，不再展示画像、购买、职业补差等无关预设。

## 互相跳转与状态

- 自测首页 → 16 型优缺点 → MBTI 介绍 → 40 题 → 免费结果。
- 16 型优缺点的某一类型 → 同一类型的 VIA × MBTI 对照；对照卡片可返回同一类型的优缺点。
- MBTI 免费结果中的 ENTP → ENTP 优缺点 / ENTP 的 VIA 对照，不改动本人的问卷答案。
- VIA 介绍 → 72 题 → 均分排序 → VIA × MBTI 对照 / 16 型优缺点。
- 自测“回看免费结果” → “我的报告”的免费分类，只列完成问卷后的 MBTI 与 VIA 记录。
- 浏览参考资料或排版样例不增加“已完成”记录；“我的”结果数只计算当前两项已完成问卷。
- 选中答案立即保留。暂停、上一题、换维度或离开页面会清除自动切题定时器并解锁；续答定位第一道未答题，末题有缺题时先回补。

参数：`mbti-q=1..40`、`mbti-page=1..4`、`via-q=1..72`。参考阅读使用 `explore-type=ENTP`，优势对照使用 `via-type=ENTP`；类型参数只控制浏览筛选，不改变测评结果。

原型状态保留在当前页面内存，刷新会清除。所有新增流程不连接服务端或真实 AI。

## 内容与结果边界

MBTI 的 40 道中文题目为现有 UI 示例。结果统一为 ENTP 固定排版样例，雷达图的八项分数也明确标为展示数据，未接入正式题库和权重计分。原有 12 个长文章节及其顺序保留。

05 结果页与 09 对照表共用用户提供的 16 型名人名单，共 64 个名字。05 在性格简析后、报告目录前展示 ENTP 对应的四位；09 每型的五项优势后展示该型四位名人，筛选同步更新。每型配一句鼓励与行动引导，名人卡只显示名字与这句文案，不展示“找共鸣 · 做参照”、类型归类标题或用途说明。名单属于参考归类，并非本人确认的测评结果，不参与 MBTI 或 VIA 计分。

VIA 使用提供的 `VIA优势自评卷-72题版.html`：6 类美德、24 项优势，每项 3 个原句。按每项三题均分从高到低排序，同分按原题顺序显示；前 5 仅作本次探索性自评参考，不当作官方验证报告。样例与实际答案独立。

VIA × MBTI 使用 `优势测评整合工具.html` 第三部分的 16 型映射，属于原文件注明的探索性推断、非官方交叉验证。原表“责任”“适应”保留并标为补充描述，不纳入 24 项计分。

16 型优缺点使用 `MBTI 16型优缺点对照.html` 的原文：16 型、每型四项优点与四项盲点，按 NT/NF/SJ/SP 分类。资料用于找共鸣和理解他人，不当作测评结论或人格定论。

界面配色复用 `--canvas / --paper / --brand / --line`：浅蓝灰背景、白色卡片和蓝紫强调色。参考 HTML 的内容与数据被接入，未照搬其独立主题。
