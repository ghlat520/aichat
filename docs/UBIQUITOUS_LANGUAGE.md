# 关系清晰卡领域语言

本词汇表统一“关系清晰卡”P0 的业务语言。它只定义业务概念，不规定数据库、框架或接口实现。

## 用户与访问

**访客（Visitor）**：
尚未绑定微信身份、仍可使用免费路径的匿名使用者。
_避免使用_：匿名会员、临时会员

**用户主体（Principal）**：
为支付、跨设备取回或提醒而完成必要身份绑定的使用者。
_避免使用_：会员、账号（泛指时）

**付费客户（Customer）**：
已经创建或完成订单的用户角色；它不表示持续会员资格。
_避免使用_：会员、订阅用户

**会员（Member）**：
拥有跨任务、带期限或等级的持续权益的用户。该概念不属于 P0。
_避免使用_：用于称呼单次购买用户

## 核心交付

**关系清晰任务（Clarity Task）**：
围绕一件具体关系事件，从用户确认信息到行动与复盘结束的一次有限任务。
_避免使用_：咨询、疗程、长期会话

**免费摘要（Free Summary）**：
不以制造恐惧为目的、包含基本澄清和安全信息的完整免费交付。
_避免使用_：试读、残缺报告、诱饵报告

**密封报告（Sealed Report）**：
已经生成并通过输出安全检查，但尚未取得查看权益的完整关系清晰卡。
_避免使用_：未生成报告、待支付生成报告

**权益（Entitlement）**：
某一用户查看某一份完整报告的有效授权；它不是会员资格。
_避免使用_：会员、订阅、余额

## 商业交易

**商品（Product）**：
对用户承诺的可购买交付类型。
_避免使用_：订单、权益

**SKU**：
商品的可售卖版本标识；P0 固定为一份关系清晰卡商品。
_避免使用_：会员套餐

**价格版本（Price Version）**：
在明确生效窗口内对某一 SKU 有效的服务端权威价格。
_避免使用_：客户端价格、活动临时值

**订单（Order）**：
用户对固定商品和成交价格作出的购买请求及其生命周期记录。
_避免使用_：支付、交易流水

**支付尝试（Payment Attempt）**：
针对一个订单向支付渠道发起的一次下单、查单或支付交互。
_避免使用_：订单

**支付事件（Payment Event）**：
支付渠道通知或主动查单后，经验证形成的不可变资金事实。
_避免使用_：客户端支付成功页

**退款（Refund）**：
针对已支付订单发起并由支付渠道确认的资金退回过程。
_避免使用_：取消订单、删除报告

**账务凭证（Ledger Transaction）**：
由支付、退款或冲正事实产生的一组借贷平衡记录。
_避免使用_：订单状态、支付回调

## 运营治理

**运营人员（Operator）**：
通过受控后台执行配置、审核、客服、财务或发布职责的内部角色。
_避免使用_：管理员（未说明权限时）

**发布包（Release Bundle）**：
把候选版本、评测证据、批准、灰度和回滚点绑定在一起的发布决策对象。
_避免使用_：代码版本、部署记录

**删除回执（Deletion Receipt）**：
证明各数据领域和适用供应商已完成或未完成删除任务的状态记录。
_避免使用_：前端隐藏成功
