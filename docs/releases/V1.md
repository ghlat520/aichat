# V1 · 自有引力

冻结日期：2026-11-07（Asia/Singapore）。Git 版本标签：`v1.0.0`。本版保存此前完成的可运行产品，不包含后续“测测”参考视频中的新增功能。

## 本版内容

- 首页围绕探索自己、觉察理解、自我驱动与复盘组织，保留明亮 A 版配色；移除“我的关系卡”可见入口。
- 默认轻量流程为“三行觉察 → 一个微行动 → 三问复盘”；说一说可展开五节点深度练习。
- 十二星座含性格、事业、人际等主题及解释，并可带着观察线索写日记。
- 16 型名人图鉴：名人照片与名字、同一卡片的优点和缺点、层叠滑动与类型筛选。自测入口为“你的偶像是哪一型？”、“16 型名人图鉴，找找共鸣”。人物为类型联想，非本人测评结果。
- 自测及报告结果的 8 类当前可见内容可生成带官方小程序码的海报，并接入保存与图片转发接口。样例、演示与实际自评分别标明；预览及付费边界不扩大。
- 浏览器原型与原生小程序保留共享内容同步脚本；本地后端独立使用 loopback 18088，不占用 8080。

## 运行与事实边界

浏览器原型：`npm run ui` 后访问 `/self-growth-prototype.html`。原生小程序：用微信开发者工具打开 `miniprogram/`。同步共享内容：`npm run sync:growth-ui`。本地后端：准备被 Git 忽略的 `.env.local` 后执行 `npm run server:local`，配置说明见 `server/README.md`。

日记和日常练习在本次小程序运行内存中保存，重启及身份变化会清除；未承诺长期保存或跨设备同步。在线回复和深度引导仍为已有确定性/模板机制。小程序码使用微信官方默认主页入口；真机扫码落地、真实相册写入与聊天发送尚待验证。此版本提交不代表微信发布、生产部署、真实支付或真实 AI 服务已经完成。
